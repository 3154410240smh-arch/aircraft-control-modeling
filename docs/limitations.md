# Limitations and evidence boundaries

## Confirmed in bounded cases

The accepted corrected three-axis local-hover LQI case combined explicit native physical states/limits with two MATLAB Function algebra blocks. Recorded algorithm, simulation, actual topology/geometry/native visual review, persistence and independent recovered-model checks passed in that case. It does not prove every algorithm implementation choice or arbitrary layout.

Windows local file installer and recovery tests are independent of that case. File hashes, exact compatible reuse, conflicts, mid-write rollback, permission/download/hash failure and final ZIP extraction are checked without MATLAB.

## Disabled or not distributed

- N-LEAF and uncertified complex branch routing/Points repair.
- Arbitrary model universal automatic layout or arbitrary newly materialized networks.
- Native geometry executor/Grant/private keys/runtime transactions: not shipped or registered.
- Complex text bounding-box certification and claims that incremental layout freezes positions.

## UNVERIFIED

- All Fcn expression variants, saturation-excited complete loops, observer/scheduling algorithms not used in the case.
- Full 6DOF, large-angle flight, real vehicles, robustness/flight safety.
- Recipient Codex desktop activation, toolchain availability and other MATLAB versions.
- Successful optional Online-mode download, enterprise policy, UNC/network-share installation.
- Six unbundled specialist Skill routes; independent Agent routing regression for the accepted LQI candidate.

## Preserved failures

The original LQI integral bound caused yaw tracking failure; an error-variable collision permitted three dependent runs after a failure; early compiler caches appeared outside the intended project area. The corrected specific implementation/stop gate and final restoration passed, but those historical failures were not reclassified. Earlier no-geometry-change routeLine and unsafe Points experiments are not published as successes and do not enable those capabilities.

No Token reduction, universal speedup or all-model quality improvement is asserted. Numerical success, geometry success, file delivery and tool discovery remain separate outcomes.
