# Compatibility

| Component | Evidence | Boundary |
|---|---|---|
| Windows PowerShell 5.1+ | Local Windows system PowerShell installation/rollback tests | Other Windows builds, enterprise restrictions and network shares unverified |
| Codex Skills | Independent product app-server metadata scan found the isolated installation | Existing desktop cache and recipient Agent body activation unverified |
| MATLAB R2025a + Simulink | Accepted private corrected LQI case | Not an all-version guarantee; not re-executed for publication |
| Official SATK/MATLAB MCP | Task uses live schemas and accepted specific versions | Not installed/configured by this package; recipient backend unknown |
| Control System Toolbox / Stateflow | Case-specific LQR and MATLAB Function evidence | Required by relevant tasks; product licenses not included |
| Native geometry executor | Separately bounded certificates, not bundled here | N-LEAF/new arbitrary networks/universal layout not enabled |

Auxiliary Skills are pinned to exact historical commits and contents, not today's latest. See ../manifests/dependencies.json. Exact file equality is the installer's compatibility rule; it does not promise semantic compatibility with different versions.
