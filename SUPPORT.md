# Support

Use https://github.com/3154410240smh-arch/aircraft-control-modeling/issues for sanitized defects and questions. Include release version/hash, Windows/PowerShell/Codex versions, exact failing stage and receipt status. Do not upload production configs, secrets or private models.

For MATLAB/SATK official component issues, first distinguish tool registration, actual backend call, model operation and numerical result. Link the relevant official upstream documentation; this project cannot supply commercial licenses or guarantee unsupported native operations.

See [installation](docs/installation.md), [troubleshooting](docs/troubleshooting.md), [limitations](docs/limitations.md) and [security](SECURITY.md).
