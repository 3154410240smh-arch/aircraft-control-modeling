# Runtime evidence and observer validity

仅在多速率/混合时序异常、内部函数/求解频次、major/minor、自定义监听或观测非侵入性问题时加载。普通PID、参数、布局、中文显示不加载。这里不提供已验证的通用记录器，不自动授权新仿真、优化、插桩或模型采样语义修改。

## 1. 先定义命题与证据层

| 层 | 可支持的结论 | 不能直接推出 |
| --- | --- | --- |
| 配置采样时间 | 设定的周期 | 实际执行频次 |
| CompiledSampleTime | 当前版本/模式的编译采样分类 | 函数入口或QP调用数 |
| 原生块方法事件 | 特定Outputs/Update等方法被观察 | 内部算法必完整重算 |
| 算法函数体入口 | 该入口直接计数/可靠追踪 | 条件性求解器必被调用 |
| 求解器入口 | 直接调用证据及已验证计数 | 每次收敛、输出被接受或实时完成 |
| 指令变化 | 已记录时间/阶段的数值更新 | 所有求值次数或未采样变化 |

不经验证不建立一一映射。分别保存物理求解时间、离散保持时钟/帧标识、直接major/minor来源及各层计数。相同保持时钟可能有不同连续输入；相同物理时间可能有不同阶段。不能从时钟floor、求值重数或外围计时猜阶段；无法可靠获取就标UNVERIFIED，并限制相关结论。

## 2. 选择最小观察路径

先读现有数据/原始时间及相关源码，定位疑似信号、最早有意义分歧和问题层级，不从最大误差点预设根因。查询编译属性前核实是否触发编译/回调、目标会话与操作授权；只覆盖受影响作用域，复用已有编译证据，并以冻结版本、初态、参考、模式、控制周期和积分步长作比较基线。

优先现有日志、原生运行时接口和本机专业Skill；具体块方法问题才评估Simulink方法级调试，函数错误用MATLAB调试，耗时问题用相应性能工具。接口存在不等于当前仿真模式支持或观察不扰动；禁止为形式完整启动全轨迹Profiler。确需自定义观察器才进入下节门禁。

内部S-Function与外层MATLAB Function接口不可类推。核实实际端口数量、类型、维度、顺序及连接映射；解析真实SID/路径，包含隐藏端口/空白名。没有证据就停止该观察路线，不硬编码其他项目的端口数。

## 3. 自定义观察器门禁

按风险依次做静态接口核查、无模型的正常/故障路径测试、获准的最短代表运行及基线对照；失败不继续下一阶段。

- 独立记录attempted、committed、failed及溢出；定义它们关系和溢出处理，不用count>0证明成功。最小事件头先保存时间/标识，载荷提交状态可追踪；预分配零值不是有效记录。
- 错误锁存与最终门禁必须能阻断假PASS；不能假定回调异常会终止仿真。没有验证安全停止API时不伪称即时中断；有限StopTime是运行上界，不替代错误判定。
- 门禁检查实际接口、完整提交、时间/阶段来源、容量及错误。新增、未解释或影响有效性的警告阻断相关结论；已评审无关历史警告可保留说明，不临时放宽规则或压制警告。
- 容量与唯一控制帧数独立，按实际事件率/载荷和批准时长估计，预留明确余量。回调内不写文件、不额外求解；已有数据优先批量导出，详细轨迹限于必要窗口。
- 比较关闭修改或冻结基线的同输入/同模式/同步长输出、可取得的决策与计数。先约定容差；缺字段不能宣称路径一致。观察器源码、配置和结果绑定版本，失败原件保留，不能改阈值追认PASS。

计时、缓存、日志与监听可能改变负载、编译保留或超时分支；核查墙钟是否参与控制决策。短时悬停、无QP或非活跃分支的一致，不证明活跃优化或长轨迹非侵入性。物理输出、方法调度、内部决策与计算开销分别报告。

## 4. 分层诊断与停止

观测无效时只诊断观测器，不据其数据判被测算法故障。需要因果证据时优先冻结快照、真实量级单因素/联合微扰及受控历史传播，均须在批准范围内；输出相似或时间相关不证明唯一因果。

优化器记录应区分种子、试探候选、最佳候选、目标分项、可达/机械/信赖约束、退出、接受及最终回退；按问题选必要字段，不默认全量Hessian/活跃集日志。不把求解器退出失败、无更新返回与非法指令混为一类。

性能证据绑定版本、解释/仿真/生成代码模式、冷/热进入、计时边界与宿主负载；分阶段剖析与正式计时批次分开。软超时标记、迭代上限或桌面分位不构成硬实时保证，未部署/目标机测量即部署能力UNVERIFIED。

每阶段明确最小证据、调用/数据预算、顺序门禁及停止条件。内部G0复审不自动授权插桩、短测或反事实实验；复用已明确覆盖的批准，缺少才申请该具体操作。证据足够则不追加；缺口无法在授权预算内关闭就报告UNVERIFIED和最小后续方案，不无界重建观察器，不自动改变模型执行语义、控制策略或验收标准。
