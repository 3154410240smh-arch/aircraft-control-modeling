# Security policy

Only the published pre-release is currently reviewed; no safety-critical or flight certification is implied. Never grant a model-editing agent broader scope than the intended independent work copy.

For a vulnerability, use this repository's GitHub private vulnerability reporting feature when enabled: https://github.com/3154410240smh-arch/aircraft-control-modeling/security/advisories/new . Do not open a public issue containing exploit details, credentials, Grants, private models or production configuration. If the private feature is unavailable, do not post secrets; use GitHub's account security/report-abuse channels for platform incidents and wait for a maintainer-provided private route for project details.

Ordinary sanitized installation defects belong in Issues. Reports should identify the affected version/hash, scope, reproduction, impact and proposed mitigation. No personal email is required or published. Leaked credentials need revocation/rotation; deleting a file from the latest commit alone is insufficient.
